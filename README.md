# beginner

记录业务里的思考，把实践中反复使用的方法整理成 Skill。

这里是我个人业务思考的对外窗口，也是一份持续更新的实践档案。我会在这里分享对具体问题的理解、分析问题的方法，以及将这些方法转化为可复用工作流的尝试。

取名 **beginner**，是提醒自己保持初学者的好奇心：从问题出发，在实践中验证，随新的认识不断修正。

## 这里会放什么

- **业务思考**：记录问题背景、判断依据、决策过程与复盘，保留思考如何发生和变化。
- **方法与框架**：把零散经验整理成分析框架、检查清单和操作流程。
- **Skill**：将经过实践的方法封装成 AI 可以协助执行的工作流，配套说明、模板或脚本。

目前先从 Skill 开始积累，后续会持续补充业务思考与实践复盘。内容代表个人在具体场景下的认识，使用时请结合自己的业务背景判断。

## 如何阅读和使用

如果你关注业务方法，可以从各个 Skill 的 `SKILL.md` 开始，了解它的问题定义、判断标准和执行流程，再按需阅读 `references/` 中的材料。

如果你想实际使用某个 Skill：

1. 阅读对应说明，确认适用场景与所需输入。
2. 将完整的 Skill 目录放入所使用 AI 工具支持的技能目录；不同工具的安装方式可能不同。
3. 按说明提供素材或数据，结合自己的业务背景调整参数，并核验输出。

小游戏流量分析包含可独立运行的 Python 脚本，具体命令见其[使用说明](skills/minigame-traffic-analysis/README.md)。其他工作流可能需要研究工具、外部服务或额外素材。部分内容保留了原始业务环境中的路径和背景，使用前需要替换为自己的配置。

## 持续更新

这个仓库会随着业务实践持续生长，不设固定更新周期。

我希望每份思考尽量说清楚：**遇到了什么问题、为什么这样判断、采取了什么行动、结果如何，以及还有哪些不确定性。** 每个 Skill 则尽量明确输入、步骤、输出和适用边界，让方法能够被理解、复用和改进。

公开内容以方法与经验为主，涉及业务数据和案例时会注意脱敏。欢迎通过 [Issues](https://github.com/theonlin0725/beginner/issues) 交流问题、反馈使用体验，或讨论不同的业务判断。
