## 去重操作提示

- **同主题复现规则**：① 已覆盖（✅）且无新事实 → 禁止；② 同主题但重大新事实（正式生效 / 新处罚 / 裁决推进）→ 只写新事实；③ 进行中（🔄）仅因官方新动作复现，且间隔 ≥4 周或重大进展。
- **韩国 loot box 概率公示**：Issue 1 已是"高敏项"泛述；任何"点名具体游戏执法"新动作属同主题，按上述规则处理（Issue 5 曾误将"点名 Swordsman from Hell 执法"与基线重复，已剔除）。
- **PEGI 16 vs DFA**：角度不同（分级落地 vs 立法路径），可并存，但需在文中注明角度差异，避免重复感。
- **Roblox/UGC 平台事件**：永远归并到影响最强区域（通常西欧），不单列"全球"分类。

## event_key 聚合去重（来自信号研判层）

- 每条研判 JSON 含 `event_key`（3-8 词小写英文聚合短键，如 `"indonesia igrs steam delisting"`）。
- 新一期生成时，把候选 JSON 的 `event_key` 与上方各 Issue 的「事件描述」做语义聚合比对；命中已覆盖（✅）且无新事实 → 丢弃；命中进行中（🔄）仅因官方新动作复现。
- 例：本索引中「韩国｜Loot box 概率公示高敏项」对应候选 `event_key` 类似 `"korea lootbox probability disclosure"`；若新条目 `event_key` 同义 → 触发同主题去重规则（间隔 ≥4 周 / 重大新进展）。
- 若新事件在索引中无对应条目，则作为新增独立事件写入新一期，并同步补一行到本索引。
