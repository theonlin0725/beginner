# 海外风险雷达周报 · 正式版模板

> 本模板是 `overseas-risk-radar-weekly-run` 的 canonical 输出骨架。生成周报时**直接照抄骨架**，替换占位内容；单事件块字段规则见文末。

## 文件名约定

- 周报：`weekly_report_YYYYMMDD_正式第N期_vN.md`
- 明细：`risk_items_YYYYMMDD_正式第N期_vN.csv`

## 单个事件块字段规则

- **标题格式**：`### 国家｜【领域】标题`（西欧可细分 欧盟 / 英国 / 法国 / 德国；韩国/印尼单列国家）
- **区域热点一句话**：现象 + 影响，凝练直给，不堆数据。
- **1. 事实**：只写客观事实，不确定点客观标注（如"生效日待定""内容尚未公开"）。
- **2. 可能影响的宿主**：一行清单，不展开研判；无法明确映射写 `人工判断确认`。
- **3. 影响链路与动作价值**：可进正文但限凝练；长研判下沉 CSV 内部字段。
- **4. 行动建议**：必须具体（具体动作 + 涉及产品/页面 + 建议时限），禁"核查/评估"泛泛。
- **5. 来源**：每条 ≥1 可点击链接；权威/合规事件优先 ≥2 独立来源交叉验证；标注可信度与验证状态。

## JSON 研判项 → 周报字段映射

周报由「信号研判层」输出的 JSON（`pass_review:true` 且 `relevance≥0.6`）消费而来。映射关系：

| 研判 JSON 字段 | 落到周报的位置 |
|---|---|
| `summary_zh` | 区域热点一句话 / 事件块标题参考 |
| `fact` | `**1. 事实**`（只写客观事实，含时间） |
| `impact` | `**3. 影响链路与动作价值**`（研判，与事实分离） |
| `action` | `**4. 行动建议**`（动词开头、可动手） |
| `targets` | 推导 `**2. 可能影响的宿主**` + CSV `targets` 列 |
| `affected_games` | 标题/题材关键词（如"含宗教符号题材""休闲解谜小游戏"） |
| `nature` / `topic` / `compliance_clause` / `level` | **仅下沉 CSV 内部字段**，正文不展示风险图标与"高/中/低" |
| `event_key` | 跨期去重聚合键 + CSV id |

> 研判标准与 JSON schema 见 `signal_screening_prompt.md`；已研判示例见 `screening_example.md`。

## 一句话看全局 & 区域热点一句话写法

- 结构 = **现象（发生了什么）+ 影响（对小游戏/宿主意味着什么）**，二者浓缩进一句。
- 只保留最关键现象与影响，具体数字、机制、来源全部下沉分块正文，一句话不堆砌。
- **不出现**「发生了什么」「什么影响」提示词，不出现「上期/本期新增/相比上周」等跨期字眼，不出现「高/中/低」风险等级词，不出现「立即/尽快/持续/待观察/优先级」等时序词，不出现「过去 X 天/距今 X 天」等时间窗口规则表述。
